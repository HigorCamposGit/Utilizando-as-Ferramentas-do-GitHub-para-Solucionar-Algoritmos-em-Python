# Utilizando as Ferramentas do GitHub para Solucionar Algoritmos em Python

Repositório estruturado para o desafio prático da **DIO**, aplicando boas práticas de versionamento com Git e resolução de algoritmos fundamentais em Python.

## 📂 Estrutura do Repositório

| Arquivo | Descrição da Funcionalidade |
| :--- | :--- |
| [`concatenacao_dados.py`](./concatenacao_dados.py) | Recebe dois dados de entrada do usuário e retorna a string unificada. |
| [`verificador_par_impar.py`](./verificador_par_impar.py) | Lê um número inteiro fornecido e valida se ele é par ou ímpar utilizando operador módulo. |
| [`calculadora_simples.py`](./calculadora_simples.py) | Executa operações aritméticas básicas (`+`, `-`, `*`, `/`) com tratamento de divisão por zero. |

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Python 3.x
* **Versionamento:** Git & GitHub
* **Ambiente:** Execução local via Git Bash
