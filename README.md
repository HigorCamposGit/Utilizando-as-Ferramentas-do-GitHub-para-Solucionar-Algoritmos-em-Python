# Utilizando as Ferramentas do GitHub para Solucionar Algoritmos em Python

Repositório criado para o desafio de projeto da **DIO (Digital Innovation One)**, com o objetivo de praticar lógica de programação em Python, versionamento de código e fluxo de trabalho com Git e GitHub.

---

## 📂 Estrutura do Projeto

O repositório contém os seguintes scripts interativos na raiz:

1. **`calculadora_simples.py`**
   - Realiza operações aritméticas fundamentais (`+`, `-`, `*`, `/`) com base nas entradas informadas pelo usuário, com tratamento de erros para divisão por zero e valores inválidos.

2. **`concatenacao_dados.py`**
   - Recebe dois valores ou textos enviados pelo usuário e os combina em uma única string formatada de maneira amigável.

3. **`verificador_par_impar.py`**
   - Lê números inteiros em sequência utilizando um loop contínuo, determinando se cada número é Par ou Ímpar. 
   - Permite encerrar a execução a qualquer momento digitando **`sair`** diretamente no campo de entrada.

---

## 🚀 Como Executar os Scripts no VS Code

Certifique-se de ter o **Python** instalado em sua máquina. Abra o terminal integrado do VS Code na pasta raiz do projeto e utilize os comandos abaixo conforme o arquivo que deseja testar:

```powershell
# 1. Executar a Calculadora Simples
python calculadora_simples.py

# 2. Executar a Concatenação de Dados
python concatenacao_dados.py

# 3. Executar o Verificador de Par ou Ímpar (com opção de sair digitando 'sair')
python verificador_par_impar.py
```
